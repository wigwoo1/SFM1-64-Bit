# Decoder provenance

Unmodified C decoder and supporting headers from Igor Pavlov's official 7-Zip repository:
https://github.com/ip7z/7zip/tree/0766b733fe3e06dd2a7f9a3cfbf2108ac73abd17/C

Files were fetched from that pinned commit. Original copyright/public-domain notices remain in each file. UPSTREAM_COMMIT.txt records the revision; outputs/sfm64-vcs6-bytecode-validation.json records downloaded source SHA-256 hashes. This subset is compiled as C and linked into the x64 owned shader-cache reader. It does not use or initialize installed SFM DLLs.
